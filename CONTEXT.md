# Glossary

**batch** – A group of finished sessions reviewed together, by default 5 from one repo. One batch agent runs per batch.

**digest** – A short summary of one session that the CLI writes before a batch runs. It holds the user's messages, one line per tool call, errors, and edited files, but no assistant prose.

**ledger** – The file that lists every proposal and its status: open, accepted, rejected, or expired.

**proposal** – One suggested change from a batch, with an ID such as P12. Each proposal belongs to one category: clarity, agent-setup, or repo-for-agents.
